## Luria–Delbrück mutant simulator

[Open or download the simulator](./Luria_Delbruck_Mutant_Simulator.html).

Created by physics student **Andrea M Garcia Chavez**, this program models the standard Luria–Delbrück process and provides an interactive comparison of Darwinian and Lamarckian mutation models.

To run the simulator, download the HTML file and open it in a web browser. The interface is in Spanish.

The full horizontal gene transfer (HGT) estimator will be uploaded soon.
